# QA und Auslieferung (G6)

## Pflicht-Checks vor jeder Auslieferung
| Check | Wie | Ziel |
|---|---|---|
| Länge/Format | `ffprobe` Frames, Dauer, Auflösung | identisch mit Referenz bzw. Brief |
| Schnitte | `scripts/vergleich.py` (`schnitte.txt`: starke Schnitte beider Seiten, Mengen-Diff) | jeder Referenz-Schnitt auf demselben Frame; zusätzliche nur, wenn gewollt (im Bericht begründen) |
| Nähte | Frames N-2 bis N+2 jeder Blockgrenze nebeneinander ansehen | kein Sprung, gleicher Hintergrund/Inhalt |
| Bewegung | `scripts/bewegung.py <film.mp4> --ref <referenz.mp4>` (Bild alle 2 s + Standbild-Zähler je Abschnitt) | Bewegung ähnlich Referenz, kein eingefrorener Abschnitt |
| Sichtprüfung | Kontaktbogen über den ganzen Film selbst ansehen | Marke, Texte, keine Platzhalter, keine Fehlbilder |
| Altlasten | `grep` auf alte Marke/Demo-Namen, `data-hf-id`, `_fenster-*` | 0 Treffer |
| Prüf-Tool | `npm run check` | 0 Fehler; Warnungen begründet |
| Ton | `ebur128`, Energiekurve vs. Referenz, Cue-Timing | −14 LUFS ±1, TP < −1 dBTP |
| Datei | Web-Kopie H.264 CRF 22, AAC 192k, `-movflags +faststart`, < 30 MB | läuft auf dem Handy und in Chat-Uploads |

**Faststart nie vergessen**: Ohne `+faststart` zeigen manche Player bis zum vollständigen Laden ein Standbild („das Video bewegt sich am Anfang nicht“). ffmpeg-Ausgaben aus Vergleichs-Skripten ebenfalls remuxen (`-c copy -movflags +faststart`).

Web-Kopie:
```bash
bash <skill-dir>/scripts/sperre.sh <lauf> -- ffmpeg -loglevel error -y -i renders/<film>.mp4 -c:v libx264 -crf 22 -pix_fmt yuv420p -c:a aac -b:a 192k -movflags +faststart renders/<film>_web.mp4
```

## Auslieferung im Chat
1. Web-Kopie übergeben, Master-Pfad nennen.
2. Qualitäts-Tabelle `Check | Ist | ✓/✗`, jeder ✗ als „✗→✓“ oder als offener Punkt mit Grund.
3. Bewusste Abweichungen von der Referenz (z. B. längere deutsche Texte → kleinere Typo).
4. Offene Freigaben (Kunde, Lizenz) ausdrücklich.
5. Prozess-Stand: erledigt · offen · wer ist dran.

## Aufräumen
Zwischen-Renders (Block-Runden, Vergleichsordner, alte Fassungen) nur auf ausdrückliche Anweisung des Nutzers löschen.
